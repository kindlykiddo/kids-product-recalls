# KindlyKiddo Kids’ Product Recall Data

Weekly normalized CPSC, NHTSA, and FDA recall records for products made for or primarily used by children.

## Included files

- `kids-product-recalls.csv` — flat dataset for analysis.
- `kids-product-recalls.json` — records plus refresh, coverage and source metadata.
- `data-dictionary.csv` — field definitions.
- `CITATION.cff` — machine-readable citation metadata.
- `LICENSE-DATA.md` — public-domain and CC0 data notice.

## Canonical sources

- Live tracker: https://www.kindlykiddo.com/kids-product-recalls/
- GitHub: https://github.com/kindlykiddo/kids-product-recalls
- Hugging Face: https://huggingface.co/datasets/kindlykiddo/kids-product-recalls

Every record links to its official federal notice. Always use that notice for product identifiers, photos, remedy instructions, and current status.
